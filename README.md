# C++ Roadmap & Practice Tracker

Веб-платформа и трекер дорожной карты по C++ (стандарт C++20) с тёмной темой в стиле **LeetCode**. 
Проект предназначен для изучения языка, разбора работы компилятора и подготовки к техническим собеседованиям.

---

## 🛠 Стек технологий

* **Core:** React, Vite, JavaScript (ES6+).
* **Роутинг:** React Router DOM (вложенные и защищённые маршруты).
* **Хранилище:** LocalStorage (авторизация, прогресс по темам, серия правильных ответов).
* **Стилизация:** Чистый CSS (CSS-переменные `:root`, анимация `fadeIn`).

---

### ✨ Основной функционал

* **Главная витрина (Home):** интерактивный хаб с динамическим расчётом прогресса, структурированной дорожной картой из 3 модулей, быстрым переходом к лабораторным работам и разбором ключевых возможностей стандарта C++20 (*Concepts, Ranges, Coroutines, Modules*).
* **Каталог тем (TopicsList):** полный спектр лекционных тем с живым поиском, фильтрацией по направлениям (*Основы языка, Управление потоком, Память, Модульность, ООП*) и группировкой по уровням сложности (*Easy / Medium / Hard*).
* **Страница темы (TopicDetail):** рабочий сплит-экран с вкладками теории, синтаксиса и самоконтроля, интерактивным тренажёром кода с моментальной валидацией ответов, раздельными вопросами по конструкторам и классу `std::string`, а также окном эталонного кода с подсветкой и копированием в буфер.
* **Практические проекты (Projects):** модуль из 7 полноценных практических работ (ПР №1 — ПР №7) с чёткими критериями оценивания, разбивкой задач по пунктам ТЗ, стартовыми шаблонами кода и итоговым зачётным текстовым квестом на ООП.
* **Профиль разработчика (Profile):** персональный дашборд с расчётом уровня (LVL), очков опыта (XP), разбивкой прогресса по категориям сложности, календарём активности, системой из 5 C++ ачивок, а также экспортом и сбросом прогресса в JSON[cite: 1].
* **Авторизация (Login / Register):** двухколоночные экраны входа и регистрации со стилизованным окном C++ кода и сохранением пользовательской сессии.
