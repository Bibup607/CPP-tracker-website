# C++ Roadmap & Practice Tracker

Веб-платформа и трекер дорожной карты по C++ (стандарт C++20) с тёмной темой в стиле **LeetCode**. 
Проект предназначен для изучения языка, разбора работы компилятора и подготовки к техническим собеседованиям.

---

## 🛠 Стек технологий

* **Core:** React, Vite, JavaScript (ES6+).
* **Роутинг:** React Router DOM (вложенные и защищённые маршруты).
* **Хранилище:** LocalStorage (авторизация, прогресс по темам, серия правильных ответов).
* **Стилизация:** Чистый CSS (CSS-переменные `:root`, анимация `fadeIn`).

---

## ✨ Основной функционал

* **Каталог тем (`TopicsList`):** 24 темы с поиском, фильтрацией по категориям и сортировкой по сложности (`Easy` / `Medium` / `Hard`).
* **Страница темы (`TopicDetail`):** сплит-экран с теорией, разбором частых ошибок компилятора, тестами, интерактивным тренажёром «⚡ Что выведет код?» и кнопками навигации между уроками.
* **Профиль разработчика (`Profile`):** дашборд с уровнем (`LVL`), очками опыта (`XP`), статистикой решённых задач, календарём активности и 5 разблокируемыми C++ ачивками.
* **Авторизация (`Login` / `Register`):** двухколоночные формы со стилизованным окном C++ кода.
* **Витрина C++20 (`Home`):** карточки ключевых фичей стандарта (*Concepts*, *Ranges*, *Coroutines*, *Modules*).
