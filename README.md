# C++ Roadmap & Practice Tracker

Веб-платформа и трекер дорожной карты по C++ (стандарт C++20) с тёмной темой в стиле **LeetCode**[cite: 2, 4]. 
Проект предназначен для изучения языка, разбора работы компилятора и подготовки к техническим собеседованиям[cite: 4].

---

## 🛠 Стек технологий

* **Core:** React, Vite, JavaScript (ES6+)[cite: 3].
* **Роутинг:** React Router DOM (вложенные и защищённые маршруты)[cite: 1].
* **Хранилище:** LocalStorage (авторизация, прогресс по темам, серия правильных ответов)[cite: 5, 7, 9].
* **Стилизация:** Чистый CSS (CSS-переменные `:root`, анимация `fadeIn`)[cite: 2].

---

## ✨ Основной функционал

* **Каталог тем (`TopicsList`):** 24 темы с поиском, фильтрацией по категориям и сортировкой по сложности (`Easy` / `Medium` / `Hard`)[cite: 10].
* **Страница темы (`TopicDetail`):** сплит-экран с теорией, разбором частых ошибок компилятора, тестами, интерактивным тренажёром «⚡ Что выведет код?» и кнопками навигации между уроками[cite: 9].
* **Профиль разработчика (`Profile`):** дашборд с уровнем (`LVL`), очками опыта (`XP`), статистикой решённых задач, календарём активности и 5 разблокируемыми C++ ачивками[cite: 7].
* **Авторизация (`Login` / `Register`):** двухколоночные формы со стилизованным окном C++ кода[cite: 5, 8].
* **Витрина C++20 (`Home`):** карточки ключевых фичей стандарта (*Concepts*, *Ranges*, *Coroutines*, *Modules*)[cite: 4].
